# OpenClaw Starter 🎯

> 一键配置你的专属 AI 助手

## 快速开始

```bash
# 1. 克隆
git clone https://github.com/adenzhou1350/openclaw-starter.git
cd openclaw-starter

# 2. 安装
bash scripts/install.sh

# 3. 选择人格
cp presets/archetype/coordinator/SOUL.md ~/.openclaw/workspace/
```

## 人格预设

- `archetype/` - 角色原型
- `mbti/` - 16 种 MBTI
- `anime/` - 动漫角色

## 项目结构

```
openclaw-starter/
├── presets/          # 预设库
├── scripts/         # 安装脚本
└── README.md
```
